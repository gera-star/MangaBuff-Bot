# 2R2R — программа для MangaBuff

**2R2R** — приложение для Windows, которое выполняет повторяющиеся действия на MangaBuff автоматически. Оно может собирать награды, добывать руду, читать главы ради бонусных карт, проводить бои и отправлять уведомления. Ход работы виден в окне программы, а при сворачивании в область уведомлений Windows программа может продолжать работу в фоне.

## Скачать и установить

1. Откройте [последние версии 2R2R](https://github.com/gera-star/MangaBuff-Bot/releases/latest).
2. Скачайте установщик **2R2R-Setup.exe**. Если доступен портативный архив ZIP, его можно использовать без обычной установки.
3. Запустите программу. Если Windows предупредит, что приложение неизвестно системе, нажмите **«Подробнее» → «Выполнить в любом случае»**. Это предупреждение может появляться, потому что приложение не подписано цифровым сертификатом.

## Первый запуск

1. Войдите в аккаунт MangaBuff. На экране входа предусмотрены кнопки **ВКонтакте, Discord, Яндекс и Google**, а также вход по электронной почте и паролю.
2. Просмотрите раздел **«Модули»**. Здесь показано, за что отвечает каждая автоматическая задача; переключатели позволяют включать и отключать настраиваемые функции.
3. Нажмите **«Запустить»**. На главной странице появятся состояние программы, ближайшее действие и статистика за день.

## Что умеет программа

- **Ежедневные награды:** отмечает посещение сайта и забирает доступные награды.
- **Шахта и кирка:** добывает руду и покупает улучшения, когда хватает ресурсов.
- **Арена:** подбирает колоду, проводит бои и открывает боевые сундуки.
- **Пробуждение карт:** использует бесплатные возможности пробуждения, если эта функция включена.
- **Вечерний кубок:** выполняет бои кубка в предусмотренное игрой время.
- **Чтение глав:** читает главы ради бонусных карт и ежедневного задания.
- **Башня Разлома:** забирает награды экспедиций и отправляет отряд в следующий поход.
- **Реклама:** просматривает доступные видео за алмазы.
- **Клуб:** вносит кристаллы и сообщает, если клубу нужна карта из вашей коллекции.
- **Сезонные события:** поддерживает доступные функции события, когда они включены в игре.

Набор доступных действий зависит от состояния сайта, игрового аккаунта и текущих событий. Программа не может гарантировать, что сайт всегда будет доступен или что каждое действие принесёт награду.

## Уведомления в Telegram (необязательно)

Telegram нужен только для сообщений на телефон. Без него программу всё равно можно использовать.

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram и отправьте команду `/newbot`.
2. Следуйте инструкциям BotFather и скопируйте выданный **токен** — секретный код доступа к вашему боту. Не отправляйте его посторонним.
3. Напишите созданному боту любое сообщение.
4. В 2R2R откройте раздел **«Telegram»**, вставьте токен и нажмите **«Найти номер чата»**, затем сохраните настройки и проверьте соединение.

Уведомления могут сообщать о новых картах, предложениях обмена, изменении ранга и неполадках.

## Где что находится

- **Главная:** состояние программы, ближайшее действие, карты, главы, реклама, энергия и игровой баланс.
- **Модули:** описание задач и переключатели доступных функций. У некоторых задач есть кнопка запуска вручную.
- **Telegram:** подключение уведомлений и настройка ночного или беззвучного режима.
- **Сеть:** проверка соединения и настройка прокси-сервера. Прокси обычно не нужен; используйте его, только если MangaBuff не открывается напрямую.
- **Журнал:** история действий и ошибок. Здесь можно посмотреть, что произошло.
- **Настройки:** запуск программы вместе с Windows, запуск бота при открытии приложения, обновления и действия при закрытии окна.

При закрытии окна программа спросит, свернуть ли её в область уведомлений рядом с часами или завершить работу. Это поведение также настраивается в разделе **«Настройки»**.

## Если возникла проблема

1. Проверьте, открывается ли MangaBuff в обычном браузере.
2. Убедитесь, что вход в аккаунт не требует повторного подтверждения.
3. Если сайт не открывается напрямую, проверьте раздел **«Сеть»**.
4. Откройте **«Журнал»** и посмотрите последние сообщения.
5. Кнопка **«Сообщить о проблеме»** откроет GitHub с подготовленным описанием. Перед отправкой проверьте текст.

Настройки и данные приложения хранятся в папке `%APPDATA%\\2R2R`.

## Простыми словами

- **Модуль** — отдельная задача, например чтение глав или бои на арене.
- **Область уведомлений (трей)** — место справа на панели задач Windows, рядом с часами.
- **Прокси-сервер** — промежуточное соединение с сайтом; обычному пользователю чаще всего он не нужен.
- **Токен Telegram** — секретный код, который позволяет программе отправлять сообщения от имени вашего бота.

## Для разработчиков

Для запуска из исходного кода нужен Python 3.10 или новее. В корневой папке проекта выполните:

```bash
python -m venv venv
```

В Windows активируйте окружение командой `venv\\Scripts\\activate`, затем установите зависимости:

```bash
pip install -r requirements.txt
pip install -r requirements-desktop.txt
python main.py --app
```

Фоновый режим для сервера запускается командой `python main.py --daemon`. Переменные окружения и ручная настройка нужны только тем, кто запускает проект из исходного кода; для установленного приложения вход настраивается через окно 2R2R.

## Важно

Проект предоставляется «как есть» для образовательного и личного использования. Автоматизация может не соответствовать правилам MangaBuff. Используйте программу на свой риск и учитывайте правила самого сервиса.
