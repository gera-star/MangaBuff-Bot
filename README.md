# 2R2R — автоматизация MangaBuff

**2R2R** — приложение для Windows, которое помогает автоматически выполнять повторяющиеся действия в MangaBuff: собирать доступные награды, добывать руду, читать главы ради бонусных карт, участвовать в боях и следить за игровыми событиями.

Программа показывает состояние задач, статистику и журнал действий. Её можно свернуть в область уведомлений Windows и оставить работать в фоне.

## Скачать 2R2R

Откройте [страницу последних выпусков](https://github.com/gera-star/MangaBuff-Bot/releases/latest) и скачайте установщик **2R2R-Setup.exe**. Если доступен ZIP-архив, его можно использовать как портативную версию.

При первом запуске Windows может показать предупреждение о неизвестном приложении, если файл не подписан цифровым сертификатом. Запускайте программу только если скачали её из официального репозитория 2R2R.

## Первый запуск

1. Откройте 2R2R и войдите в MangaBuff. Доступен вход через ВКонтакте, Discord, Яндекс, Google или по электронной почте и паролю.
2. Перейдите в раздел **«Модули»** и включите нужные задачи.
3. Нажмите **«Запустить»**. Состояние программы и ход работы отображаются на главной странице и в журнале.

## Возможности

- **Ежедневные награды** — получение доступных наград за посещение сайта.
- **Шахта** — добыча руды и улучшение кирки при наличии ресурсов.
- **Арена** — автоматические бои и открытие боевых сундуков.
- **Пробуждение карт** — выполнение доступных действий по развитию карт.
- **Вечерний кубок** — участие в боях кубка в игровое время.
- **Чтение глав** — чтение глав ради бонусных карт и ежедневных заданий.
- **Башня Разлома** — получение наград экспедиций и отправка отряда в следующий поход.
- **Просмотр рекламы** — просмотр доступных видео за игровые награды.
- **Клуб** — внесение кристаллов и уведомления о запросах карт.
- **События** — поддержка доступных игровых событий.

Доступность функций зависит от MangaBuff, настроек программы и состояния игрового аккаунта. Получение конкретной награды не гарантируется.

## Уведомления в Telegram (по желанию)

Telegram нужен только для отправки уведомлений на телефон. Без него основными функциями приложения можно пользоваться и дальше.

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram и отправьте `/newbot`.
2. Выполните инструкции и скопируйте выданный токен — секретный код доступа к вашему боту. Не публикуйте его.
3. Напишите созданному боту любое сообщение.
4. В 2R2R откройте раздел **«Telegram»**, вставьте токен и нажмите **«Найти номер чата»**.
5. Сохраните настройки и проверьте соединение.

## Разделы приложения

- **Главная** — состояние программы, ближайшие действия и игровая статистика.
- **Модули** — список автоматических задач и переключатели их работы.
- **Telegram** — настройка уведомлений и тихого режима.
- **Сеть** — состояние соединения и настройка прокси-сервера. Прокси обычно не требуется.
- **Журнал** — история действий и сообщения об ошибках.
- **Настройки** — параметры запуска, обновления и поведение при закрытии окна.

При закрытии окна можно свернуть программу рядом с часами Windows или полностью завершить её работу.

## Если что-то не работает

1. Проверьте, открывается ли MangaBuff в обычном браузере.
2. Убедитесь, что сайт не просит заново войти в аккаунт.
3. Откройте раздел **«Журнал»** и посмотрите последние сообщения.
4. Если проблема остаётся, используйте кнопку **«Сообщить о проблеме»** и проверьте подготовленный текст перед отправкой.

Настройки приложения находятся в папке `%APPDATA%\\2R2R`.

## Простыми словами

- **Модуль** — отдельная задача, например чтение глав или бои на арене.
- **Область уведомлений** — место справа на панели задач Windows, рядом с часами.
- **Прокси-сервер** — промежуточное соединение с сайтом; обычно его не нужно настраивать.
- **Токен Telegram** — секретный код, позволяющий программе отправлять сообщения через вашего бота.

## Запуск из исходного кода

Этот раздел нужен разработчикам. Для обычного использования скачайте установщик выше.

Потребуется Python 3.10 или новее. В корневой папке проекта выполните:

```powershell
python -m venv venv
venv\\Scripts\\activate
pip install -r requirements.txt
pip install -r requirements-desktop.txt
python main.py --app
```

## Важно

2R2R предоставляется «как есть». Автоматизация может не соответствовать правилам MangaBuff. Используйте программу на свой риск и учитывайте правила сервиса.
